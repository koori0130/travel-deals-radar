## Why

台灣旅客想「說飛就飛」，卻沒有一個地方能從台北（桃園 TPE、松山 TSA）一次看到「未來 1 年最便宜的目的地」與「未來 1 個月臨時釋出的超特價」。Google Flights 沒有公開 API，Amadeus 自助 API 已關閉，單一價格 API 也抓不到航空公司的快閃促銷，因此需要自建一個以每日快取為基礎、結合價格 API 與航空公司促銷頁的查找頁面。

## What Changes

- 新增每日排程的價格資料管線：查詢 TPE、TSA 出發、約 30 到 50 個熱門目的地的未來 1 年最低價，整理成 JSON 快取並累積歷史價格。
- 新增航空公司促銷資料來源：第一批涵蓋台灣虎航、樂桃、酷航、捷星、亞洲航空的促銷頁，每筆促銷記錄價格、出發日期範圍、開賣與截止時間、原始連結；抓不到的快閃促銷提供人工補登入口。
- 新增「旅行說飛就飛」互動頁面，含兩個視圖：
  - 未來 1 年最便宜：依目的地列出最低價與對應月份，可切換 TPE／TSA。
  - 未來 1 個月特價：以航空公司促銷為主，依價格與截止時間排序，並標示出處。
- 頁面只負責查找與導流，「前往訂購」直接連到航空公司或訂票網站。
- 來源健康警示：任一航空公司來源超過設定天數沒有更新時，頁面與維運輸出都要標示。
- 促銷視圖可依航空公司複選篩選。
- 每筆票價與促銷附預填路線與日期的 Google Flights 與 Skyscanner 查價連結，並提供 Google Flights 探索連結；促銷連結若只是航空公司首頁，明確標示。
- 檢視狀態存於網址 hash，返回與重新整理後還原。

## Non-Goals (optional)

- 不做訂票、付款或會員功能。
- 不做真正的全球任意目的地即時掃描，第一版限定熱門目的地。
- 第一版不納入旅行社與比價站（雄獅、易遊網、五福、Trip.com、Skyscanner 台灣站等），待確認其條款與資料開放方式後再評估。
- 不使用 Google Flights 或其他條款禁止自動抓取的來源。
- 不混排單程與來回價格比價。

## Capabilities

### New Capabilities

- `fare-price-pipeline`: 每日抓取 TPE、TSA 出發至熱門目的地的最低價，輸出快取 JSON 並保存歷史價格。
- `airline-promo-feed`: 取得並正規化航空公司促銷資料（含人工補登與來源健康警示）。
- `deals-explorer-page`: 「旅行說飛就飛」前端頁面，含未來 1 年最便宜與未來 1 個月特價兩個視圖。

### Modified Capabilities

(none)

## Impact

- 全新專案內容，目前沒有既有程式碼受影響。
- 新增：排程後端（價格抓取與各航空公司抓取器）、快取 JSON 資料檔、靜態前端頁面。
- 外部依賴：一個可自助申請的價格 API（待實測 Duffel、Ignav 等後決定）、各航空公司公開促銷頁；需各家條款確認。
- API 金鑰只存在於後端排程環境，不進前端。
